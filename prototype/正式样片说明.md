# ANGLE 正式样片

采用已选定的 B 版变画与 F 版表面反光。此前的所有对照文件保持原样。

## 打开

本地地址：http://127.0.0.1:5189/

如服务未运行，在本目录执行 `node final-server.cjs`，保持终端开启，再访问上述地址。需要 Node.js。请使用本地服务打开，避免直接双击 HTML 导致浏览器限制 Canvas 图片读取。

## 操作

- 按住卡片左右拖动；也可用角度滑块、左/中/右按钮，或聚焦卡片后按左右方向键。
- “一次上传三张照片”按文件选择器给出的顺序填入左、中、右位置，缩略图显示实际顺序。
- 上传后自动打开裁剪窗口；点击任意缩略图也可重新调整。窗口内可切换左、中、右三张照片。
- 拖动照片调整位置，缩放滑块支持 100%–300%；也可通过水平、垂直滑块精细移动。图片始终铺满卡片，防止露出空白。
- 每张照片可独立重置或替换。点击“完成调整”保留构图，“取消”或 Esc 恢复本次打开编辑器之前的构图（不会撤销照片上传）。
- 裁剪保留原图，在原图上重新绘制，反复调整不会累计裁剪损失。照片仅在当前浏览器内处理，刷新页面后恢复示例图片。
- 可调整镭射强度、使用原色对照或自动演示。

独立页面为 `final.html`。默认示例为喷火龙 ex、皮卡丘 ex、月亮伊布 ex，分别使用 `pokemon-charizard.png`、`pokemon-pikachu.png`、`pokemon-umbreon.png`，尺寸均为 733×1024。原 `source.jpg` 和此前对照仍保留。这是本地样片，未部署到公网。

## 验证

生成脚本核对 B 版变画及 F 版反光绘制代码与 F 对照版本一致，并验证内联脚本语法。浏览器实际检查三张批量上传、单张替换、数量错误提示、拖拽角度响应及宽/窄窗口布局。

裁剪功能已检查上传后自动打开、缩放、二维拖动、各张参数独立保留、完成后重新打开、重置及取消恢复。
